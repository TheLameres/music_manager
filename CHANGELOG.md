# Changelog

Все значимые изменения в проекте Music Manager документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.0.0] - 2024-09-18

### Добавлено

#### Основные возможности
- Поддержка чтения и записи ID3-тегов для форматов: MP3, FLAC, OGG, M4A, WMA, OPUS, APE
- Графический интерфейс на PySide6 с тремя основными вкладками
- Автоматическая организация файлов в иерархическую структуру `{Исполнитель}/{Год} - {Альбом}/{Номер} - {Название}`
- Синхронизация с съемными носителями (аналог Windows Media Player Sync)

#### Вкладка "Библиотека"
- Добавление аудиофайлов и папок в библиотеку
- Просмотр метаданных в табличном виде
- Редактирование тегов отдельных файлов
- Пакетное редактирование тегов для нескольких файлов
- Отображение информации о файле: размер, формат, битрейт, длительность

#### Вкладка "Организация"
- Предпросмотр изменений перед организацией
- Режимы копирования и перемещения файлов
- Автоматическое создание папок по метаданным
- Обработка конфликтов имен файлов
- Прогресс-бар для длительных операций

#### Вкладка "Синхронизация"
- Автоматическое обнаружение съемных носителей (Windows/Linux)
- Выбор пользовательской папки для синхронизации
- Расчет плана синхронизации с предпросмотром
- Опция организации файлов на устройстве
- Опция удаления лишних файлов с устройства
- Отображение информации о свободном месте
- Проверка достаточности места перед синхронизацией

#### Архитектура
- Принцип "один класс - один файл"
- Разделение на слои: Models, Services, Views
- Использование Qt Signals/Slots для связи компонентов
- Обработка ошибок на всех уровнях
- Progress callbacks для длительных операций

#### Сервисы
- `TagService` - работа с метаданными различных форматов
- `OrganizeService` - организация файлов в структуру
- `SyncService` - синхронизация с устройствами

#### Документация
- README.md - основная документация
- USAGE.md - подробное руководство пользователя
- ARCHITECTURE.md - описание архитектуры и структуры
- INSTALL.md - инструкции по установке и деплою
- examples.py - примеры использования API
- CHANGELOG.md - история изменений

#### Инфраструктура
- Poetry для управления зависимостями
- Скрипт быстрого запуска `run.py`
- Базовые unit-тесты
- .gitignore для Python проектов

### Известные ограничения

- Синхронизация не поддерживает MTP (Android устройства) - только файловые системы
- Предпросмотр синхронизации показывает максимум 20 файлов в каждой категории
- Нет поддержки обложек альбомов (album art) в первой версии
- Нет встроенного аудио-плеера

### Технические детали

- Python: 3.10+
- PySide6: 6.6.0+
- mutagen: 1.47.0+
- pathvalidate: 3.2.0+
