# Music Manager - Структура проекта

## Обзор

Music Manager - это приложение на Python с GUI для управления музыкальной библиотекой, редактирования ID3-тегов и синхронизации с устройствами.

## Описание модулей

### Модели (Models)

#### `audio_file.py`
- **Класс**: `AudioFile`
- **Назначение**: Представление аудиофайла с метаданными
- **Ключевые методы**:
  - `get_organized_path()` - генерирует путь в иерархической структуре
  - Properties для доступа к размеру и имени файла

### Сервисы (Services)

#### `tag_service.py`
- **Класс**: `TagService`
- **Назначение**: Чтение и запись метаданных аудиофайлов
- **Поддерживаемые форматы**: MP3, FLAC, OGG, M4A, WMA, OPUS, APE
- **Ключевые методы**:
  - `read_tags()` - чтение метаданных из файла
  - `write_tags()` - запись метаданных в файл
  - `is_supported()` - проверка поддержки формата

#### `organize_service.py`
- **Класс**: `OrganizeService`
- **Назначение**: Организация файлов в иерархическую структуру
- **Формат**: `{Исполнитель}/{Год} - {Альбом}/{Номер} - {Название}`
- **Ключевые методы**:
  - `organize_file()` - организует один файл
  - `organize_files()` - пакетная организация
  - `preview_organization()` - предпросмотр изменений

#### `sync_service.py`
- **Класс**: `SyncService`
- **Назначение**: Синхронизация с съемными носителями (аналог Windows Media Player Sync)
- **Ключевые методы**:
  - `get_available_drives()` - поиск съемных носителей
  - `calculate_sync_plan()` - расчет плана синхронизации
  - `sync_to_device()` - выполнение синхронизации
  - `get_device_info()` - информация о свободном месте

### UI компоненты (Views)

#### `main_window.py`
- **Класс**: `MainWindow`
- **Назначение**: Главное окно приложения
- **Содержит**: QTabWidget с тремя вкладками

#### `library_tab.py`
- **Класс**: `LibraryTab`
- **Назначение**: Управление библиотекой и редактирование тегов
- **Функции**:
  - Добавление файлов и папок
  - Просмотр метаданных в таблице
  - Редактирование тегов
  - Пакетное редактирование

#### `organize_tab.py`
- **Класс**: `OrganizeTab`
- **Назначение**: Организация файлов в структуру
- **Функции**:
  - Выбор целевой папки
  - Предпросмотр изменений
  - Копирование или перемещение файлов

#### `sync_tab.py`
- **Класс**: `SyncTab`
- **Назначение**: Синхронизация с устройствами
- **Функции**:
  - Автоопределение устройств
  - Предпросмотр синхронизации
  - Выборочное удаление файлов
  - Отображение свободного места

### Точка входа

#### `main.py`
- **Функция**: `main()`
- **Назначение**: Инициализация QApplication и запуск GUI

## Поток данных

```
1. Пользователь добавляет файлы
   ↓
2. LibraryTab → TagService.read_tags()
   ↓
3. Создается список AudioFile объектов
   ↓
4. Signal files_loaded передает данные в OrganizeTab и SyncTab
   ↓
5. Пользователь выбирает действие:
   
   a) Редактирование тегов:
      LibraryTab → TagService.write_tags() → Файл обновлен
   
   b) Организация:
      OrganizeTab → OrganizeService.organize_files() → Файлы скопированы/перемещены
   
   c) Синхронизация:
      SyncTab → SyncService.sync_to_device() → Устройство синхронизировано
```

## Принципы разработки

1. **Один класс - один файл** ✓
2. **Разделение ответственности**: Models, Services, Views
3. **Использование Qt Signals/Slots** для связи компонентов
4. **Progress callbacks** для длительных операций
5. **Обработка ошибок** на всех уровнях

## Расширяемость

### Добавление нового формата
Отредактируйте `tag_service.py`, добавьте методы `_read_*_tags()` и `_write_*_tags()`

### Добавление новой вкладки
1. Создайте новый файл `*_tab.py`
2. Унаследуйте от `QWidget`
3. Добавьте в `main_window.py`

### Добавление нового сервиса
1. Создайте файл `*_service.py`
2. Реализуйте статические методы
3. Используйте в соответствующих вкладках

## Особенности реализации

### Обработка различных форматов
TagService использует библиотеку `mutagen` с специфичными классами для каждого формата (EasyID3, FLAC, MP4, OggVorbis)

### Автоопределение устройств
SyncService использует разные методы для Windows (GetDriveTypeW) и Linux (/media, /mnt)

### Безопасность файловых операций
- Проверка существования файлов
- Создание резервных копий при конфликтах имен
- Возможность отмены длительных операций

### UI/UX
- Прогресс-бары для длительных операций
- Предпросмотр перед выполнением действий
- Подтверждения для деструктивных операций
