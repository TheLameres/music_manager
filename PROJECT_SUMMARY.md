# Music Manager - Резюме проекта

## 📋 Обзор

**Music Manager** - полнофункциональное приложение для управления музыкальной библиотекой с графическим интерфейсом, разработанное на Python 3 и PySide6.

## ✅ Реализованные требования

### Основные возможности

✅ **Работа с ID3-тегами**
- Чтение метаданных из аудиофайлов
- Редактирование тегов (название, исполнитель, альбом, год, трек, жанр)
- Пакетное редактирование
- Поддержка форматов: MP3, FLAC, OGG, M4A, WMA, OPUS, APE

✅ **Сортировка по папкам**
- Автоматическая организация в иерархию: `{Исполнитель}/{Год выпуска} - {Альбом}/{Номер трека} - {Название трека}`
- Предпросмотр изменений
- Режимы копирования и перемещения

✅ **Синхронизация с устройствами**
- Автоматическое обнаружение съемных носителей
- Копирование файлов на устройство
- Создание иерархии папок на устройстве
- Удаление лишних файлов (опционально)
- Предпросмотр синхронизации
- Аналог функции Sync из Windows Media Player

✅ **Технологический стек**
- Python 3.10+
- PySide6 (Qt6)
- Poetry для управления зависимостями

✅ **Архитектурный принцип**
- Один класс - один файл

## 🎯 Ключевые компоненты

### Модели (1 файл)
- `audio_file.py` - Представление аудиофайла с метаданными

### Сервисы (3 файла)
- `tag_service.py` - Работа с метаданными (чтение/запись тегов)
- `organize_service.py` - Организация файлов в иерархию
- `sync_service.py` - Синхронизация с устройствами

### UI компоненты (4 файла)
- `main_window.py` - Главное окно с вкладками
- `library_tab.py` - Библиотека и редактирование тегов
- `organize_tab.py` - Организация файлов
- `sync_tab.py` - Синхронизация с устройствами

### Точка входа (1 файл)
- `main.py` - Инициализация и запуск приложения

**Итого: 10 классов в 10 файлах** ✅

## 🔧 Технические детали

### Зависимости
```toml
python = "^3.10"
PySide6 = "^6.6.0"      # GUI framework
mutagen = "^1.47.0"     # Работа с аудио-метаданными
pathvalidate = "^3.2.0" # Валидация путей
```

### Поддерживаемые форматы
- MP3 (ID3v2)
- FLAC (Vorbis Comments)
- OGG (Vorbis Comments)
- M4A/MP4 (iTunes tags)
- WMA (Windows Media)
- OPUS (Vorbis Comments)
- APE (APEv2)

### Поддерживаемые метаданные
- Название трека (Title)
- Исполнитель (Artist)
- Альбом (Album)
- Год выпуска (Year)
- Номер трека (Track Number)
- Жанр (Genre)
- Длительность (Duration) - только чтение
- Битрейт (Bitrate) - только чтение

### Платформы
- ✅ Windows (автоопределение съемных дисков)
- ✅ Linux (поддержка /media и /mnt)
- ✅ macOS (базовая поддержка)

## 📊 Архитектурные решения

### Принципы
1. **Один класс - один файл** ✅
2. **Разделение ответственности** (Models, Services, Views)
3. **Qt Signals/Slots** для связи компонентов
4. **Progress callbacks** для длительных операций
5. **Обработка ошибок** на всех уровнях

### Поток данных
```
User Input → UI Components → Services → File System
     ↑                              ↓
     └──────── Signals/Callbacks ←──┘
```

### Расширяемость
- ✅ Легко добавить новый формат (в `tag_service.py`)
- ✅ Легко добавить новую вкладку (наследование от `QWidget`)
- ✅ Легко добавить новый сервис (статические методы)
