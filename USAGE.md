# Music Manager - Установка и использование

## Быстрый старт

### Установка зависимостей

```bash
# Установите Poetry, если еще не установлен
pip install poetry

# Установите зависимости проекта
poetry install
```

### Запуск приложения

```bash
# Через Poetry
poetry run music-manager

# Или напрямую через Python (без установки)
python run.py
```

## Структура проекта

```
music_manager/
├── audio_file.py           # Модель аудиофайла
├── tag_service.py          # Сервис работы с метаданными
├── organize_service.py     # Сервис организации файлов
├── sync_service.py         # Сервис синхронизации с устройствами
├── main_window.py          # Главное окно приложения
├── library_tab.py          # Вкладка библиотеки
├── organize_tab.py         # Вкладка организации
├── sync_tab.py             # Вкладка синхронизации
└── main.py                 # Точка входа
```

## Возможности

### 1. Библиотека (вкладка "Библиотека")

- Добавление аудиофайлов и папок
- Просмотр метаданных (ID3-теги)
- Редактирование тегов отдельных файлов
- Пакетное редактирование тегов
- Поддержка форматов: MP3, FLAC, OGG, M4A, WMA, OPUS, APE

### 2. Организация (вкладка "Организация")

- Автоматическая организация файлов в иерархию:
  ```
  {Исполнитель}/{Год выпуска} - {Альбом}/{Номер трека} - {Название трека}
  ```
- Предпросмотр изменений
- Режимы: копирование или перемещение файлов
- Автоматическое создание папок

### 3. Синхронизация (вкладка "Синхронизация")

- Автоматическое обнаружение съемных носителей
- Синхронизация библиотеки с устройством
- Опция организации файлов на устройстве
- Опция удаления лишних файлов с устройства
- Предпросмотр плана синхронизации
- Отображение информации о свободном месте

## Примеры использования

### Редактирование тегов

1. Откройте вкладку "Библиотека"
2. Нажмите "Добавить папку" и выберите папку с музыкой
3. Выберите файл в таблице
4. Измените теги в полях редактирования
5. Нажмите "Сохранить теги"

### Пакетное редактирование

1. Выберите несколько файлов (Ctrl+Click или Shift+Click)
2. Заполните нужные поля (например, "Альбом" и "Год")
3. Нажмите "Применить ко всем"

### Организация библиотеки

1. Загрузите файлы в библиотеку
2. Откройте вкладку "Организация"
3. Выберите целевую папку
4. Нажмите "Предпросмотр" для проверки
5. Выберите режим (копирование/перемещение)
6. Нажмите "Организовать"

### Синхронизация с устройством

1. Подключите USB-накопитель или SD-карту
2. Откройте вкладку "Синхронизация"
3. Выберите устройство из списка или укажите папку
4. Настройте опции синхронизации
5. Нажмите "Предпросмотр синхронизации"
6. Нажмите "Синхронизировать"

## Технические детали

### Поддерживаемые форматы

- **MP3** - полная поддержка ID3v2
- **FLAC** - Vorbis комментарии
- **OGG** - Vorbis комментарии
- **M4A/MP4** - iTunes теги
- **WMA** - Windows Media теги
- **OPUS** - Vorbis комментарии
- **APE** - APEv2 теги

### Метаданные

Поддерживаемые поля:
- Название трека (Title)
- Исполнитель (Artist)
- Альбом (Album)
- Год выпуска (Year)
- Номер трека (Track Number)
- Жанр (Genre)
- Длительность (Duration)
- Битрейт (Bitrate)

### Архитектура

Приложение следует принципу "один класс - один файл" и использует:
- **Модели**: `AudioFile` - представление аудиофайла
- **Сервисы**: изолированная бизнес-логика для работы с тегами, организации и синхронизации
- **UI компоненты**: отдельные вкладки для каждой функции

## Зависимости

- **Python 3.10+**
- **PySide6** - Qt6 биндинги для Python (GUI)
- **mutagen** - библиотека для работы с аудио-метаданными
- **pathvalidate** - валидация и очистка путей файловой системы
