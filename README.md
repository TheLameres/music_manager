# Music Manager

Приложение для управления музыкальной библиотекой с поддержкой:
- Редактирования ID3-тегов (MP3, FLAC, и другие форматы)
- Автоматической сортировки файлов по структуре: `{Исполнитель}/{Год} - {Альбом}/{Номер} - {Название}`
- Синхронизации с съемными носителями (по аналогии с Windows Media Player)

## Установка

```bash
poetry install
```

## Запуск

```bash
poetry run music-manager
```

## Возможности

- Просмотр и редактирование метаданных аудиофайлов
- Пакетное редактирование тегов
- Организация файлов в иерархическую структуру
- Синхронизация библиотеки с устройствами
- Поддержка форматов: MP3, FLAC, OGG, M4A, WMA и др.
